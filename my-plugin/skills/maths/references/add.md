# Add

Sum two or more numbers.

## Steps

1. Collect all the numbers to be added.
2. Add them together, left to right.
3. Return the total.

## Edge cases

- Mixed positive and negative numbers: add them normally (a negative number reduces the sum).
- Decimal numbers: keep full precision, don't round unless the user asks.
- Non-numeric input: ask the user to clarify instead of guessing.

## Example

Input: 12, -4, 7.5
Calculation: 12 + (-4) + 7.5 = 15.5
Result: 15.5
