Perform arithmetic operations on the numbers given by the user.

Supported operations:
- **Add** — see [references/add.md](references/add.md)
- **Subtract** — see [references/subtract.md](references/subtract.md)
- **Multiply**: return the product of the given numbers.
- **Divide**: return the quotient of the given numbers. If the divisor is zero, tell the user division by zero is undefined instead of computing a result.

For add and subtract, read the matching reference file before answering so the steps and edge cases are followed precisely. Always show the calculation, not just the final number.
